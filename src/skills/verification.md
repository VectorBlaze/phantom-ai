# Verification Skill

## Purpose
Make sure PHANTØM verifies its work before declaring a task complete.

## Verification Levels

### Level 1 — Syntax
Check that modified code can be parsed or imported.

### Level 2 — Execution
Run the relevant script, command, application, or development server.

### Level 3 — Functional
Exercise the changed functionality and inspect the result.

### Level 4 — Regression
Check that important existing functionality still works.

## Rules
- Verification is mandatory for implementation tasks whenever technically possible.
- Never say "working" based only on successfully writing a file.
- Treat terminal errors as failures until resolved.
- If verification cannot be performed, explicitly state what could not be verified.

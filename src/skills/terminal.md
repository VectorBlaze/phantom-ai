# Terminal Execution Skill

## Purpose
Use the terminal to inspect, run, test, and verify the project.

## Workflow
1. Determine the correct working directory.
2. Inspect the project when necessary.
3. Run the smallest useful command.
4. Read stdout and stderr.
5. If the command fails, diagnose the output.
6. Fix the issue.
7. Re-run the command.

## Rules
- Never assume a command succeeded.
- Never claim a server is running without checking.
- Use appropriate timeouts.
- Avoid destructive commands unless explicitly required.
- Do not delete project files as a shortcut to fixing an issue.
- Prefer project-local commands and existing scripts.

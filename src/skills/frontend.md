# Frontend Engineering Skill

## Purpose
Create polished, responsive, maintainable interfaces.

## Workflow
1. Inspect the existing frontend structure.
2. Understand the current layout and component system.
3. Preserve the existing visual language unless the user requests a redesign.
4. Build the requested UI.
5. Check spacing, typography, hierarchy, responsiveness, and interaction states.
6. Run the application.
7. Verify the result in the browser when possible.

## UI Principles
- Keep interfaces clean and purposeful.
- Avoid unnecessary visual clutter.
- Maintain consistent spacing.
- Use clear hierarchy.
- Make interactive elements obviously interactive.
- Keep buttons and controls functional.
- Prefer reusable components.
- Avoid excessive animations.
- Ensure layouts work at different viewport sizes.

## CSS Rules
- Inspect existing CSS before replacing it.
- Avoid duplicated styles.
- Use the project's existing conventions when possible.
- Fix the underlying layout issue instead of stacking random overrides.

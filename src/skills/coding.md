# Coding Skill

## Purpose
Build clean, working software rather than merely explaining code.

## Workflow
1. Inspect the existing project before changing anything.
2. Identify the smallest set of files that need modification.
3. Preserve existing functionality unless the task requires changing it.
4. Implement the requested feature completely.
5. Check imports, dependencies, paths, and syntax.
6. Run the relevant application or test.
7. Read the actual output.
8. Fix errors before reporting completion.

## Rules
- Prefer simple solutions.
- Reuse existing utilities.
- Avoid unnecessary dependencies.
- Do not create duplicate functionality.
- Do not rewrite unrelated files.
- Do not claim success without verification.
- If something fails, debug the actual error instead of guessing.
